# AlignersFarm for Windows

Desktop app for the AlignersFarm portal (https://portal.alignerfarm.com).

**Download:** https://github.com/Neke147/alignersfarm-desktop/releases/latest/download/AlignersFarm-Setup.exe

The app opens the portal in its own window and updates itself (menu **AlignersFarm → Check for updates…**).
To publish a new version, change `version` in `package.json` – GitHub builds and publishes it automatically.
